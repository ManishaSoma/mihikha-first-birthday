MIHIKHA'S ROYAL PRINCESS INVITATION — VERSION 2

PREVIEW
1. Open index.html in Chrome.
2. Click “Enter the Castle” to see the transition into the invitation.
3. The first screen has a twilight castle-like gradient by default. Add an image you have rights to use as images/castle.jpg for a castle backdrop.

CUSTOMIZE
- Edit index.html with Notepad or Visual Studio Code.
- Replace [AGE], [Birthday Date], [Party Time], [Venue Name and Address], [GOOGLE_MAPS_LINK], and [RSVP_LINK].
- Change COUNTDOWN_DATE near the bottom. Example: 2026-12-05T18:00:00
- Add photos in the images folder named mihikha1.jpg through mihikha6.jpg.
- To add music, put a song you have rights to use at images/birthday-song.mp3, then add this inside the audio element:
  <source src="images/birthday-song.mp3" type="audio/mpeg">

PUBLISH FOR FREE
- Create a free Netlify account.
- Visit https://app.netlify.com/drop
- Drag the unzipped project folder (containing index.html and images/) into the upload area.
- To update, deploy the updated folder again.

Note: Countdown date, Maps, RSVP and photo fields are placeholders until you edit them.
